# ARM 栈帧详解

> ARM32和ARM64架构栈帧结构完整规范

## ARM32 栈帧

### 标准栈帧布局

```
高地址
┌─────────────────────────────────────────┐
│           调用者栈帧                    │
├─────────────────────────────────────────┤
│  栈参数（第5个及以后）                  │
├─────────────────────────────────────────┤ ← 调用时SP
│  保存的LR                               │
├─────────────────────────────────────────┤
│  保存的R11 (FP)                         │  ← R11 (帧指针)
├─────────────────────────────────────────┤
│  保存的寄存器 (R4-R10)                  │
├─────────────────────────────────────────┤
│  局部变量                               │
├─────────────────────────────────────────┤
│  对齐填充（如需要）                     │
└─────────────────────────────────────────┘ ← SP (8字节对齐)
低地址
```

### ARM32 函数示例

```asm
@ ARM32 函数
my_function:
    @ 序言
    push    {r4-r11, lr}        @ 保存寄存器
    add     r11, sp, #28        @ 设置帧指针
    sub     sp, sp, #16         @ 分配局部变量
    
    @ 访问参数
    @ r0-r3: 参数1-4
    @ [r11+8]: 参数5
    
    @ 访问局部变量
    str     r0, [sp, #0]        @ 局部变量1
    
    @ 尾声
    add     sp, sp, #16
    pop     {r4-r11, pc}        @ 恢复并返回
```

## ARM64 栈帧

### 标准栈帧布局

```
高地址
┌─────────────────────────────────────────┐
│           调用者栈帧                    │
├─────────────────────────────────────────┤
│  栈参数（第9个及以后）                  │
├─────────────────────────────────────────┤ ← 调用时SP
│  保存的X29 (FP) 和 X30 (LR)            │  ← X29 (帧指针)
├─────────────────────────────────────────┤
│  保存的寄存器 (X19-X28)                │
├─────────────────────────────────────────┤
│  保存的SIMD寄存器 (V8-V15)             │
├─────────────────────────────────────────┤
│  局部变量                               │
├─────────────────────────────────────────┤
│  对齐填充（如需要）                     │
└─────────────────────────────────────────┘ ← SP (16字节对齐)
低地址
```

### ARM64 函数示例

```asm
// ARM64 函数
my_function:
    // 序言
    stp     x29, x30, [sp, #-32]!   // 保存FP和LR，分配32字节
    mov     x29, sp                  // 设置帧指针
    stp     x19, x20, [sp, #16]     // 保存callee-saved寄存器
    
    // 访问参数
    // x0-x7: 参数1-8
    // [x29+16]: 参数9
    
    // 访问局部变量
    str     x0, [sp, #8]            // 局部变量
    
    // 尾声
    ldp     x19, x20, [sp, #16]     // 恢复寄存器
    ldp     x29, x30, [sp], #32     // 恢复FP/LR并释放栈
    ret
```

## 帧指针链

### ARM32 帧指针链

```
┌─────────────────┐
│   当前栈帧      │
│  R11 ──────────┼──┐
└─────────────────┘  │
                     ▼
┌─────────────────┐  │
│   调用者栈帧    │◄─┘
│  R11 ──────────┼──┐
└─────────────────┘  │
                     ▼
┌─────────────────┐  │
│  更早的栈帧     │◄─┘
│  R11 = 0        │    (栈底)
└─────────────────┘
```

### ARM64 帧指针链

```
┌─────────────────┐
│   当前栈帧      │
│  X29 ──────────┼──┐
│  X30 (LR)       │  │
└─────────────────┘  │
                     ▼
┌─────────────────┐  │
│   调用者栈帧    │◄─┘
│  X29 ──────────┼──┐
│  X30 (LR)       │  │
└─────────────────┘  │
                     ▼
```

## 叶子函数优化

### ARM32 叶子函数

```asm
@ 不调用其他函数，可省略保存LR
leaf_function:
    @ 无需保存LR
    add     r0, r0, r1
    bx      lr
```

### ARM64 叶子函数

```asm
// 不调用其他函数
leaf_function:
    // 无需保存X30
    add     x0, x0, x1
    ret
```
