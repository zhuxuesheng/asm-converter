# 栈帧结构概述

> 栈帧的基本概念、组成部分和各架构通用原则

## 概述

栈帧（Stack Frame）是函数调用时在栈上分配的内存区域，用于存储：

- 返回地址
- 保存的寄存器
- 局部变量
- 函数参数（某些情况）

---

## 栈帧基本概念

### 栈的特性

| 特性 | 说明 |
|------|------|
| **增长方向** | 向低地址增长（大多数架构） |
| **LIFO** | 后进先出 |
| **栈指针** | 指向栈顶（最低有效地址） |
| **帧指针** | 指向当前栈帧基址（可选） |

### 栈帧组成

```
高地址
┌─────────────────────────────────────────────────────────────────────────────┐
│                        调用者栈帧                                           │
├─────────────────────────────────────────────────────────────────────────────┤
│                        参数区                                               │
│                   (超出寄存器的参数)                                        │
├─────────────────────────────────────────────────────────────────────────────┤
│                        返回地址                                             │
├─────────────────────────────────────────────────────────────────────────────┤ ← 帧指针(可选)
│                        保存的帧指针                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                        保存的寄存器                                         │
├─────────────────────────────────────────────────────────────────────────────┤
│                        局部变量                                             │
├─────────────────────────────────────────────────────────────────────────────┤
│                        临时空间                                             │
└─────────────────────────────────────────────────────────────────────────────┘ ← 栈指针
低地址
```

## 帧指针 vs 栈指针

### 使用帧指针

```asm
; 函数序言
push    rbp             ; 保存旧帧指针
mov     rbp, rsp        ; 设置新帧指针
sub     rsp, 32         ; 分配局部变量

; 访问参数和局部变量
mov     rax, [rbp+16]   ; 参数（固定偏移）
mov     [rbp-8], rax    ; 局部变量

; 函数尾声
mov     rsp, rbp        ; 恢复栈指针
pop     rbp             ; 恢复帧指针
ret
```

### 省略帧指针

```asm
; 函数序言（无帧指针）
sub     rsp, 40         ; 分配空间

; 访问参数和局部变量
mov     rax, [rsp+48]   ; 参数（相对SP）
mov     [rsp+8], rax    ; 局部变量

; 函数尾声
add     rsp, 40
ret
```

### 对比

| 特性 | 使用帧指针 | 省略帧指针 |
|------|------------|------------|
| 调试 | 容易 | 需要调试信息 |
| 性能 | 略慢 | 略快 |
| 寄存器 | 占用RBP | 多一个可用寄存器 |
| 栈回溯 | 简单 | 需要展开信息 |

## 栈对齐

### 对齐要求

| 架构 | 对齐要求 |
|------|----------|
| x86 | 4字节（推荐16字节） |
| x64 | 16字节 |
| ARM32 | 8字节 |
| ARM64 | 16字节 |
| PPC32 | 16字节 |
| PPC64 | 16字节 |

### 对齐原因

1. **SIMD指令**：SSE/AVX要求16/32字节对齐
2. **性能**：对齐访问更快
3. **ABI要求**：调用约定规定

---

## 各架构栈帧对比

| 特性 | x86 | x64 | ARM32 | ARM64 | PPC |
|------|-----|-----|-------|-------|-----|
| 栈增长 | 向下 | 向下 | 向下 | 向下 | 向下 |
| 对齐 | 4/16 | 16 | 8 | 16 | 16 |
| 帧指针 | EBP | RBP | R11 | X29 | R1 |
| 链接寄存器 | 无 | 无 | LR | LR | LR |
| Red Zone | 无 | 128(Linux) | 无 | 无 | 288/512 |
