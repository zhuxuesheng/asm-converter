# PowerPC 栈帧详解

> PowerPC架构栈帧结构完整规范，包含链接区和参数保存区

## PPC32 栈帧

### 标准栈帧布局

```
高地址
┌─────────────────────────────────────────┐
│           调用者栈帧                    │
├─────────────────────────────────────────┤
│  参数保存区（第9个及以后）              │
├─────────────────────────────────────────┤
│  链接区                                 │
│  ┌─────────────────────────────────────┐│
│  │  [SP+4]: LR保存位置                 ││
│  │  [SP+0]: 回链指针                   ││
│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤ ← 调用者SP
│  FPR保存区 (f14-f31)                   │
├─────────────────────────────────────────┤
│  GPR保存区 (r14-r31)                   │
├─────────────────────────────────────────┤
│  CR保存区                               │
├─────────────────────────────────────────┤
│  局部变量                               │
├─────────────────────────────────────────┤
│  参数保存区（为被调用函数）             │
├─────────────────────────────────────────┤
│  链接区                                 │
│  ┌─────────────────────────────────────┐│
│  │  [SP+4]: LR保存位置                 ││
│  │  [SP+0]: 回链指针                   ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘ ← SP (16字节对齐)
低地址
```

### PPC32 函数示例

```asm
my_function:
    stwu    r1, -48(r1)         # 分配栈帧，更新回链
    mflr    r0                  # 获取LR
    stw     r0, 52(r1)          # 保存LR到调用者链接区
    stw     r14, 24(r1)         # 保存callee-saved寄存器
    stw     r15, 28(r1)
    
    # 函数体
    # 参数: r3-r10
    # 栈参数: [r1+56], [r1+60]...
    
    lwz     r14, 24(r1)         # 恢复寄存器
    lwz     r15, 28(r1)
    lwz     r0, 52(r1)          # 恢复LR
    mtlr    r0
    addi    r1, r1, 48          # 释放栈帧
    blr
```

## PPC64 栈帧

### ELFv2 栈帧布局

```
高地址
┌─────────────────────────────────────────┐
│           调用者栈帧                    │
├─────────────────────────────────────────┤
│  参数保存区（可选）                     │
├─────────────────────────────────────────┤
│  链接区 (32字节)                        │
│  ┌─────────────────────────────────────┐│
│  │  [SP+24]: TOC保存位置               ││
│  │  [SP+16]: LR保存位置                ││
│  │  [SP+8]:  CR保存位置                ││
│  │  [SP+0]:  回链指针                  ││
│  └─────────────────────────────────────┘│
├─────────────────────────────────────────┤ ← 调用者SP
│  FPR保存区 (f14-f31)                   │
├─────────────────────────────────────────┤
│  GPR保存区 (r14-r31)                   │
├─────────────────────────────────────────┤
│  VR保存区 (v20-v31)                    │
├─────────────────────────────────────────┤
│  局部变量                               │
├─────────────────────────────────────────┤
│  参数保存区（为被调用函数）             │
├─────────────────────────────────────────┤
│  链接区 (32字节)                        │
└─────────────────────────────────────────┘ ← SP (16字节对齐)
│                                         │
│  Red Zone (512字节)                     │
│                                         │
低地址
```

### PPC64 ELFv2 函数示例

```asm
my_function:
0:  addis   r2, r12, .TOC.-0b@ha
    addi    r2, r2, .TOC.-0b@l
.Lmy_function_lep:
    .localentry my_function, .-my_function
    
    mflr    r0
    std     r0, 16(r1)          # 保存LR
    stdu    r1, -64(r1)         # 分配栈帧
    std     r14, 32(r1)         # 保存寄存器
    std     r15, 40(r1)
    
    # 函数体
    
    ld      r14, 32(r1)
    ld      r15, 40(r1)
    addi    r1, r1, 64
    ld      r0, 16(r1)
    mtlr    r0
    blr
```

## 链接区详解

### 链接区组成

| 偏移 (PPC32) | 偏移 (PPC64 ELFv2) | 内容 |
|--------------|-------------------|------|
| SP+0 | SP+0 | 回链指针 |
| SP+4 | SP+8 | CR保存 |
| - | SP+16 | LR保存 |
| - | SP+24 | TOC保存 |

### 回链指针

回链指针形成栈帧链表，用于栈回溯：

```
栈帧链:
[当前SP+0] → [调用者SP] → [更早SP] → ... → 0
```
