# 操作系统调用约定差异概述

> 不同操作系统在调用约定上的差异分析，包括用户态调用和系统调用

## 概述

虽然CPU架构定义了基本的调用约定，但不同操作系统在实现细节上存在差异。本章节重点分析Linux、Windows和macOS在x64架构上的调用约定差异。

### 调用类型

| 调用类型 | 说明 | 示例 |
|----------|------|------|
| **用户态调用** | 应用程序内部的函数调用 | 调用库函数、自定义函数 |
| **系统调用** | 应用程序请求内核服务 | 文件操作、进程管理 |

## 用户态调用约定对比

### x64架构用户态调用

| 特性 | Linux (System V) | Windows (MS x64) | macOS (System V) |
|------|------------------|------------------|------------------|
| **整数参数** | RDI,RSI,RDX,RCX,R8,R9 | RCX,RDX,R8,R9 | RDI,RSI,RDX,RCX,R8,R9 |
| **浮点参数** | XMM0-XMM7 | XMM0-XMM3 | XMM0-XMM7 |
| **返回值** | RAX, RDX | RAX | RAX, RDX |
| **栈对齐** | 16字节 | 16字节 | 16字节 |
| **Shadow Space** | 无 | 32字节 | 无 |
| **Red Zone** | 128字节 | 无 | 128字节 |
| **栈清理** | 调用者 | 调用者 | 调用者 |


### 关键差异说明

#### 参数寄存器顺序

```
Linux/macOS (System V AMD64 ABI):
┌─────┬─────┬─────┬─────┬─────┬─────┐
│ 1st │ 2nd │ 3rd │ 4th │ 5th │ 6th │
│ RDI │ RSI │ RDX │ RCX │ R8  │ R9  │
└─────┴─────┴─────┴─────┴─────┴─────┘

Windows (Microsoft x64):
┌─────┬─────┬─────┬─────┐
│ 1st │ 2nd │ 3rd │ 4th │
│ RCX │ RDX │ R8  │ R9  │
└─────┴─────┴─────┴─────┘
```

#### Shadow Space vs Red Zone

```
Windows Shadow Space:
高地址
┌─────────────────────────────────────────┐
│           调用者栈帧                    │
├─────────────────────────────────────────┤
│  Shadow Space (32字节)                  │  ← 调用者必须分配
│  [RSP+8]  参数1位置                     │
│  [RSP+16] 参数2位置                     │
│  [RSP+24] 参数3位置                     │
│  [RSP+32] 参数4位置                     │
├─────────────────────────────────────────┤
│  返回地址                               │
└─────────────────────────────────────────┘ ← RSP (调用后)
低地址

Linux/macOS Red Zone:
高地址
┌─────────────────────────────────────────┐
│           栈帧内容                      │
├─────────────────────────────────────────┤ ← RSP
│                                         │
│           Red Zone (128字节)            │  ← 叶子函数可用
│                                         │
└─────────────────────────────────────────┘
低地址
```

## 系统调用对比

### x64系统调用机制

| 特性 | Linux | Windows | macOS |
|------|-------|---------|-------|
| **指令** | syscall | syscall | syscall |
| **系统调用号** | RAX | RAX | RAX (+ 0x2000000) |
| **参数1** | RDI | R10 | RDI |
| **参数2** | RSI | RDX | RSI |
| **参数3** | RDX | R8 | RDX |
| **参数4** | R10 | R9 | R10 |
| **参数5** | R8 | 栈 | R8 |
| **参数6** | R9 | 栈 | R9 |
| **返回值** | RAX | RAX | RAX |
| **错误指示** | RAX为负值 | CF标志 | CF标志 |

### 系统调用号差异

| 功能 | Linux | Windows | macOS |
|------|-------|---------|-------|
| read | 0 | - | 0x2000003 |
| write | 1 | - | 0x2000004 |
| open | 2 | - | 0x2000005 |
| close | 3 | - | 0x2000006 |
| exit | 60 | - | 0x2000001 |

> **注意**: Windows不鼓励直接使用syscall，系统调用号在不同版本间可能变化。

## 寄存器保存规则对比

### Caller-saved (Volatile)

| 寄存器 | Linux | Windows | macOS |
|--------|-------|---------|-------|
| RAX | ✓ | ✓ | ✓ |
| RCX | ✓ | ✓ | ✓ |
| RDX | ✓ | ✓ | ✓ |
| RSI | ✓ | - | ✓ |
| RDI | ✓ | - | ✓ |
| R8-R9 | ✓ | ✓ | ✓ |
| R10-R11 | ✓ | ✓ | ✓ |
| XMM0-XMM5 | ✓ | ✓ | ✓ |

### Callee-saved (Non-volatile)

| 寄存器 | Linux | Windows | macOS |
|--------|-------|---------|-------|
| RBX | ✓ | ✓ | ✓ |
| RBP | ✓ | ✓ | ✓ |
| RSI | - | ✓ | - |
| RDI | - | ✓ | - |
| R12-R15 | ✓ | ✓ | ✓ |
| XMM6-XMM15 | - | ✓ | - |
