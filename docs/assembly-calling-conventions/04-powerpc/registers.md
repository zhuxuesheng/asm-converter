# PowerPC 寄存器参考

> PowerPC架构寄存器完整参考，包含GPR、FPR、向量寄存器和特殊寄存器

## 概述

PowerPC架构提供丰富的寄存器集，包括：

- **32个通用寄存器（GPR）**：用于整数运算和地址计算
- **32个浮点寄存器（FPR）**：用于浮点运算
- **32个向量寄存器（VR）**：用于SIMD运算（VMX/Altivec）
- **32个VSX寄存器（VSR）**：扩展向量标量寄存器
- **特殊寄存器**：控制和状态寄存器

---

| GPR3 | r3 | 32位 | 64位 | 参数1/返回值 | Volatile |
| GPR4 | r4 | 32位 | 64位 | 参数2/返回值高位 | Volatile |
| GPR5 | r5 | 32位 | 64位 | 参数3 | Volatile |
| GPR6 | r6 | 32位 | 64位 | 参数4 | Volatile |
| GPR7 | r7 | 32位 | 64位 | 参数5 | Volatile |
| GPR8 | r8 | 32位 | 64位 | 参数6 | Volatile |
| GPR9 | r9 | 32位 | 64位 | 参数7 | Volatile |

| GPR13 | r13 | 32位 | 64位 | 小数据/线程指针 | 专用 |
| GPR14-31 | r14-r31 | 32位 | 64位 | 通用 | Non-volatile |


### GPR详细说明

#### r0 - 特殊用途寄存器

- **不能用作基址寄存器**：在寻址模式中，r0被解释为0
- **常用于临时存储**：保存LR、CR等
- **Volatile**：函数调用后可能被修改

```asm
# r0的特殊行为
lwz     r3, 0(r0)       # 实际访问地址0，不是r0的值
lwz     r3, 0(r1)       # 访问r1指向的地址

# 正确使用r0
mflr    r0              # 保存LR到r0
stw     r0, 4(r1)       # 存储到栈
```

#### r1 - 栈指针（SP）

- **始终指向当前栈帧底部**
- **必须16字节对齐**
- **回链指针存储在[r1+0]**

```asm
# 栈帧分配
stwu    r1, -32(r1)     # PPC32: 分配32字节栈帧
stdu    r1, -64(r1)     # PPC64: 分配64字节栈帧
```

#### r2 - TOC指针

| 架构 | 用途 |
|------|------|
| PPC32 | 系统保留（某些ABI用于小数据） |
| PPC64 ELFv1 | TOC指针（必须保存） |
| PPC64 ELFv2 | TOC指针（调用者保存） |

#### r3-r10 - 参数寄存器

- **r3**：第1个参数，也用于返回值
- **r4**：第2个参数，64位返回值高位（PPC32）
- **r5-r10**：第3-8个参数

#### r11 - 环境指针

- 用于嵌套函数访问外层作用域
- PIC代码中用于计算GOT地址
- Volatile

#### r12 - 临时/函数入口

- ELFv2中用于计算TOC（全局入口点）
- 间接调用时存储目标地址
- Volatile

#### r13 - 线程/小数据指针

| 架构 | 用途 |
|------|------|
| PPC32 | 小数据区基址（SDA） |
| PPC64 | 线程局部存储（TLS）指针 |

#### r14-r31 - 被调用者保存寄存器

- 函数必须保存和恢复这些寄存器
- 共18个寄存器可用于局部变量

## 向量寄存器（VMX/Altivec）

### 寄存器列表

| 寄存器 | 大小 | 用途 | 保存责任 |
|--------|------|------|----------|
| v0-v1 | 128位 | 临时寄存器 | Volatile |
| v2-v13 | 128位 | 参数传递 | Volatile |
| v14-v19 | 128位 | 临时寄存器 | Volatile |
| v20-v31 | 128位 | 通用 | Non-volatile |

### 向量数据类型

| 类型 | 元素数量 | 元素大小 |
|------|----------|----------|
| vector signed char | 16 | 8位 |
| vector unsigned char | 16 | 8位 |
| vector signed short | 8 | 16位 |
| vector unsigned short | 8 | 16位 |
| vector signed int | 4 | 32位 |
| vector unsigned int | 4 | 32位 |
| vector float | 4 | 32位 |

### 向量寄存器使用示例

```asm
# 加载向量
    lvx     v2, 0, r3           # 从r3地址加载128位到v2

# 向量加法
    vaddsws v4, v2, v3          # 有符号字加法（饱和）
    vadduwm v4, v2, v3          # 无符号字加法（模）

# 存储向量
    stvx    v4, 0, r4           # 存储v4到r4地址
```

## VSX寄存器

### 寄存器映射

VSX（Vector Scalar Extension）扩展了向量处理能力，提供64个128位寄存器：

```
VSX寄存器映射:
┌─────────────────────────────────────────────────────────────────────────────┐
│  VSR0-VSR31:  与FPR0-FPR31的高64位重叠                                      │
│  VSR32-VSR63: 与VR0-VR31完全重叠                                            │
└─────────────────────────────────────────────────────────────────────────────┘

VSR0  ←→ FPR0 (高64位)
VSR1  ←→ FPR1 (高64位)
...
VSR31 ←→ FPR31 (高64位)
VSR32 ←→ VR0
VSR33 ←→ VR1
...
VSR63 ←→ VR31
```

### VSX数据类型

| 类型 | 元素数量 | 元素大小 |
|------|----------|----------|
| vector double | 2 | 64位 |
| vector long long | 2 | 64位 |
| vector unsigned long long | 2 | 64位 |

## 特殊寄存器

### 链接寄存器（LR）

| 属性 | 值 |
|------|-----|
| 大小 | 32/64位 |
| 用途 | 存储函数返回地址 |
| 保存责任 | Volatile |

```asm
# LR操作
mflr    r0              # 移动LR到r0
mtlr    r0              # 移动r0到LR
blr                     # 分支到LR（返回）
bl      func            # 分支并链接（调用）
```

### 计数寄存器（CTR）

| 属性 | 值 |
|------|-----|
| 大小 | 32/64位 |
| 用途 | 循环计数/间接分支目标 |
| 保存责任 | Volatile |

```asm
# CTR循环
    li      r3, 100
    mtctr   r3              # 设置循环次数
loop:
    # 循环体
    bdnz    loop            # CTR--, 非零则跳转

# CTR间接调用
    mtctr   r12             # 设置目标地址
    bctrl                   # 调用
```

### 条件寄存器（CR）

CR是32位寄存器，分为8个4位字段（CR0-CR7）：

```
CR寄存器结构:
┌─────┬─────┬─────┬─────┬─────┬─────┬─────┬─────┐
│ CR0 │ CR1 │ CR2 │ CR3 │ CR4 │ CR5 │ CR6 │ CR7 │
└─────┴─────┴─────┴─────┴─────┴─────┴─────┴─────┘
  位    位    位    位    位    位    位    位
 0-3   4-7  8-11 12-15 16-19 20-23 24-27 28-31

每个CRn字段:
┌────┬────┬────┬────┐
│ LT │ GT │ EQ │ SO │
└────┴────┴────┴────┘
 小于 大于 等于 溢出
```

| 字段 | 保存责任 | 说明 |
|------|----------|------|
| CR0 | Volatile | 整数比较默认目标 |
| CR1 | Volatile | 浮点比较默认目标 |
| CR2-CR4 | Non-volatile | 被调用者必须保存 |
| CR5-CR7 | Volatile | 临时使用 |

```asm
# CR操作
    cmpwi   r3, 0           # 比较，结果存入CR0
    cmpwi   cr1, r4, 10     # 比较，结果存入CR1
    
    beq     equal           # CR0.EQ=1则跳转
    blt     cr1, less       # CR1.LT=1则跳转
    
# 保存/恢复CR
    mfcr    r0              # 移动CR到r0
    mtcr    r0              # 移动r0到CR
```


### 定点异常寄存器（XER）

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | SO | Summary Overflow（累积溢出） |
| 1 | OV | Overflow（溢出） |
| 2 | CA | Carry（进位） |
| 25-31 | 字节计数 | 用于字符串指令 |

```asm
# XER操作
    mfxer   r0              # 移动XER到r0
    mtxer   r0              # 移动r0到XER
    
# 带溢出检测的加法
    addo.   r3, r4, r5      # 加法，设置OV和CR0
```

### 浮点状态和控制寄存器（FPSCR）

| 位 | 名称 | 说明 |
|----|------|------|
| 0 | FX | 浮点异常摘要 |
| 1 | FEX | 浮点启用异常摘要 |
| 2 | VX | 无效操作异常摘要 |
| 3 | OX | 溢出异常 |
| 4 | UX | 下溢异常 |
| 5 | ZX | 除零异常 |
| 6 | XX | 不精确异常 |
| 30-31 | RN | 舍入模式 |

| 舍入模式 | RN值 | 说明 |
|----------|------|------|
| 最近偶数 | 00 | 默认 |
| 向零 | 01 | 截断 |
| 向+∞ | 10 | 向上 |
| 向-∞ | 11 | 向下 |

### VRSAVE寄存器

用于指示哪些向量寄存器正在使用：

| 属性 | 值 |
|------|-----|
| 大小 | 32位 |
| 用途 | 向量寄存器使用掩码 |
| 保存责任 | Non-volatile |

```asm
# VRSAVE操作
    mfspr   r0, 256         # 读取VRSAVE
    mtspr   256, r0         # 写入VRSAVE
```

## 寄存器保存规则汇总

### Volatile（调用者保存）

| 类别 | 寄存器 |
|------|--------|
| GPR | r0, r3-r12 |
| FPR | f0-f13 |
| VR | v0-v19 |
| 特殊 | LR, CTR, XER, CR0, CR1, CR5-CR7 |

### Non-volatile（被调用者保存）

| 类别 | 寄存器 |
|------|--------|
| GPR | r14-r31 |
| FPR | f14-f31 |
| VR | v20-v31 |
| 特殊 | CR2-CR4, VRSAVE |

### 专用寄存器

| 寄存器 | 用途 |
|--------|------|
| r1 | 栈指针 |
| r2 | TOC指针（PPC64） |
| r13 | 线程指针（PPC64）/小数据指针（PPC32） |
