# 寄存器快速参考

本文档提供所有架构寄存器的快速查阅表，便于开发者快速查找寄存器用途和调用约定规则。

---

## x86/x64 架构

### x64 通用寄存器

| 寄存器 | 32位 | 16位 | 8位(低) | 8位(高) | 用途 | System V | Microsoft |
|--------|------|------|---------|---------|------|----------|-----------|
| RAX | EAX | AX | AL | AH | 返回值、累加器 | 易失性 | 易失性 |
| RBX | EBX | BX | BL | BH | 通用 | 非易失性 | 非易失性 |
| RCX | ECX | CX | CL | CH | 计数器、第4/1参数 | 易失性 | 易失性 |
| RDX | EDX | DX | DL | DH | 数据、第3/2参数 | 易失性 | 易失性 |
| RSI | ESI | SI | SIL | - | 源索引、第2参数 | 易失性 | 非易失性 |
| RDI | EDI | DI | DIL | - | 目标索引、第1参数 | 易失性 | 非易失性 |
| RBP | EBP | BP | BPL | - | 帧指针 | 非易失性 | 非易失性 |
| RSP | ESP | SP | SPL | - | 栈指针 | 特殊 | 特殊 |
| R8 | R8D | R8W | R8B | - | 第5/5参数 | 易失性 | 易失性 |
| R9 | R9D | R9W | R9B | - | 第6/6参数 | 易失性 | 易失性 |
| R10 | R10D | R10W | R10B | - | 通用 | 易失性 | 易失性 |
| R11 | R11D | R11W | R11B | - | 通用 | 易失性 | 易失性 |
| R12 | R12D | R12W | R12B | - | 通用 | 非易失性 | 非易失性 |
| R13 | R13D | R13W | R13B | - | 通用 | 非易失性 | 非易失性 |
| R14 | R14D | R14W | R14B | - | 通用 | 非易失性 | 非易失性 |
| R15 | R15D | R15W | R15B | - | 通用 | 非易失性 | 非易失性 |

|----------|----------------|---------------|
| 第1个整数参数 | RDI | RCX |
| 第2个整数参数 | RSI | RDX |
| 第3个整数参数 | RDX | R8 |

| 第6个整数参数 | R9 | 栈 |

| 第4个浮点参数 | XMM3 | XMM3 |
| 整数返回值 | RAX | RAX |
| 浮点返回值 | XMM0 | XMM0 |

| 寄存器 | 大小 | System V | Microsoft | 用途 |
|--------|------|----------|-----------|------|
| XMM0 | 128位 | 易失性 | 易失性 | 浮点参数1/返回值 |
| XMM1 | 128位 | 易失性 | 易失性 | 浮点参数2 |
| XMM2 | 128位 | 易失性 | 易失性 | 浮点参数3 |
| XMM3 | 128位 | 易失性 | 易失性 | 浮点参数4 |
| XMM4 | 128位 | 易失性 | 易失性 | 浮点参数5 |

| XMM6 | 128位 | 易失性 | 非易失性 | 浮点参数7/通用 |
| XMM7 | 128位 | 易失性 | 非易失性 | 浮点参数8/通用 |

### x86 调用约定寄存器使用

| 调用约定 | 参数传递 | 返回值 | 栈清理 | 保留寄存器 |
|----------|----------|--------|--------|------------|
| cdecl | 栈（右到左） | EAX/EDX:EAX | 调用者 | EBX, ESI, EDI, EBP |
| stdcall | 栈（右到左） | EAX/EDX:EAX | 被调用者 | EBX, ESI, EDI, EBP |
| fastcall | ECX, EDX + 栈 | EAX/EDX:EAX | 被调用者 | EBX, ESI, EDI, EBP |

| X3 | W3 | 参数4 | 易失性 |
| X4 | W4 | 参数5 | 易失性 |
| X5 | W5 | 参数6 | 易失性 |
| X6 | W6 | 参数7 | 易失性 |
| X7 | W7 | 参数8 | 易失性 |
| X8 | W8 | 间接结果位置 | 易失性 |
| X9-X15 | W9-W15 | 临时寄存器 | 易失性 |
| X16 | W16 | IP0 (过程内调用临时) | 易失性 |
| X17 | W17 | IP1 (过程内调用临时) | 易失性 |
| X18 | W18 | 平台寄存器 | 平台相关 |
| X19-X28 | W19-W28 | 被调用者保存 | 非易失性 |

## PowerPC 架构

### PowerPC 通用寄存器 (GPR)

| 寄存器 | 用途 | 调用约定 |
|--------|------|----------|
| R0 | 临时/特殊 | 易失性 |
| R1 | 栈指针 (SP) | 特殊 |
| R2 | TOC指针 (PPC64) | 特殊 |
| R3 | 参数1/返回值 | 易失性 |
| R4 | 参数2/返回值(高32位) | 易失性 |
| R5 | 参数3 | 易失性 |
| R6 | 参数4 | 易失性 |
| R7 | 参数5 | 易失性 |
| R8 | 参数6 | 易失性 |
| R9 | 参数7 | 易失性 |
| R10 | 参数8 | 易失性 |
| R11 | 环境指针/临时 | 易失性 |
| R12 | 函数入口临时 | 易失性 |
| R13 | 线程指针 | 特殊 |
| R14-R31 | 被调用者保存 | 非易失性 |

### PowerPC 浮点寄存器 (FPR)

| 寄存器 | 用途 | 调用约定 |
|--------|------|----------|
| F0 | 临时 | 易失性 |
| F1 | 浮点参数1/返回值 | 易失性 |
| F2-F8 | 浮点参数2-8 | 易失性 |
| F9-F13 | 临时 | 易失性 |
| F14-F31 | 被调用者保存 | 非易失性 |

### PowerPC 特殊寄存器

| 寄存器 | 用途 | 说明 |
|--------|------|------|
| LR | 链接寄存器 | 存储返回地址 |
| CTR | 计数寄存器 | 循环计数/间接分支 |
| CR | 条件寄存器 | 8个4位字段(CR0-CR7) |
| XER | 定点异常寄存器 | 溢出/进位标志 |
| FPSCR | 浮点状态控制寄存器 | 浮点异常/舍入模式 |

## 快速对比表

### 参数传递寄存器对比

| 参数 | x64 SysV | x64 MS | ARM64 | ARM32 | PPC |
|------|----------|--------|-------|-------|-----|
| 1 | RDI | RCX | X0 | R0 | R3 |
| 2 | RSI | RDX | X1 | R1 | R4 |
| 3 | RDX | R8 | X2 | R2 | R5 |
| 4 | RCX | R9 | X3 | R3 | R6 |
| 5 | R8 | 栈 | X4 | 栈 | R7 |
| 6 | R9 | 栈 | X5 | 栈 | R8 |
| 7 | 栈 | 栈 | X6 | 栈 | R9 |
| 8 | 栈 | 栈 | X7 | 栈 | R10 |

### 返回值寄存器对比

| 类型 | x64 SysV | x64 MS | ARM64 | ARM32 | PPC |
|------|----------|--------|-------|-------|-----|
| 整数 | RAX | RAX | X0 | R0 | R3 |
| 整数(128位) | RAX:RDX | - | X0:X1 | R0:R1 | R3:R4 |
| 浮点 | XMM0 | XMM0 | V0 | S0/D0 | F1 |

### 栈指针和帧指针对比

| 架构 | 栈指针 | 帧指针 | 链接寄存器 |
|------|--------|--------|------------|
| x64 | RSP | RBP | 栈上 |
| ARM64 | SP | X29 | X30 |
| ARM32 | R13/SP | R11/FP | R14/LR |
| PPC | R1 | R1(可选R31) | LR |
